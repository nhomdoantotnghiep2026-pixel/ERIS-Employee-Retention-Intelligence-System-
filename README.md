# ERIS-Employee-Retention-Intelligence-System

## Chạy nhanh

Từ thư mục gốc của đồ án:

```bash
npm run dev
```

Nếu port `5173` đang bận, Vite sẽ tự chuyển sang port kế tiếp. Xem dòng `Local:` trong terminal rồi mở đúng link đó.

Các lệnh thường dùng:

```bash
npm run dev
npm run build
npm run preview
```

Nếu mới tải source và chưa có `node_modules`:

```bash
npm run install:frontend
```
