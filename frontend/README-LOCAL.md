## Run

From this folder:

```powershell
npm.cmd install
npm.cmd run dev
```

Open http://localhost:5173/dashboard or http://localhost:5173/login.
Use the demo account selector to switch roles. Authentication, employee data,
and AI metrics are demonstrations; no real backend authentication is configured.

Build: `npm.cmd run build`.
Changes here do not automatically sync back to Figma Make.
