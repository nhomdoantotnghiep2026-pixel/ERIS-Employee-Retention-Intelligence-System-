# ERIS local

Source exported from Figma Make on 2026-09-23.

## Run

From the repository root:

```powershell
npm.cmd run dev
```

Or from this folder:

```powershell
npm.cmd install
npm.cmd run dev
```

Open the URL printed after `Local:` in the terminal. Usually it is
http://localhost:5173/. If that port is busy, Vite will pick the next
available port.

Useful pages: http://localhost:5173/, http://localhost:5173/dashboard, or
http://localhost:5173/login.
Use the demo account selector to switch roles. Authentication, employee data,
and AI metrics are demonstrations; no real backend authentication is configured.

Build from the repository root: `npm.cmd run build`.
Build from this folder: `npm.cmd run build`.
Changes here do not automatically sync back to Figma Make.
